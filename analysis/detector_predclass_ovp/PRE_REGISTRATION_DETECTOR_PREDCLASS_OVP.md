## 0.5 Descriptor Justification Layer (v0.2 seed; locked disclosure — NOT an admission gate)

1. **Mechanism (disclosed).** *Class-asymmetric reliability — a pure-intercept asymmetry in base correctness rate by predicted class.* Measured, not hypothesized: DETECTOR_DIRECTION_OVP's non-gating diagnostic found accuracy **0.773 when the detector predicts AI (`pred=1`, n=652) vs 0.632 when it predicts Human (`pred=0`, n=1348)** — a 14.1-pt gap; the detector predicts Human more often and is least reliable there. This candidate is generated by the ledger's own surfaced failure structure.
2. **Baseline-blindness argument (mechanistic Ancestry; see §3).** `B = max(p,1−p)` discards *which* class — a base-rate-by-class difference is structurally invisible to a magnitude-only feature. `[B,p]` (DETECTOR_DIRECTION_OVP) carried direction only through a slope-coupled term and provably **could not represent a pure-intercept shift** → Inconclusive. `[B, pred]` hands the linear model the direction bit as a clean intercept shifter.
3. **What is actually being tested (the genuine uncertainty).** The verdict does **not** follow from the known 14-pt marginal gap; it hinges on whether **folded confidence already encodes the asymmetry**. If the detector is appropriately *less confident* when predicting Human (so low confidence already predicts low accuracy), confidence is a sufficient statistic → `pred` adds little → Not-Validated. If confidence is similar across classes but accuracy differs → `pred` adds a lot → Validated. **Sealed until the locked run** (the HDG-beyond-confidence is NOT the marginal gap and is NOT computed pre-lock).
4. **Pre-committed interpretations (locked; anti-rescue):**
   - **Validated:** the predicted-class direction carries correctness information beyond folded confidence — the class-asymmetry is genuinely confidence-orthogonal.
   - **Not-Validated:** `pred` adds nothing demonstrable beyond folded confidence — confidence **already encodes** the class-asymmetry (the detector is appropriately less confident on the class it is worse at). **Do NOT reinterpret as "wrong substrate"** — the substrate is eligible and the asymmetry is real; the null *is* the finding (confidence is a sufficient statistic for the asymmetry too).
   - **Inconclusive:** `pred`'s incremental contribution sits in the band; no legitimacy claim.
5. **Surface foil (paired disconfirming control; §4/§6).** **Permuted `pred`** — predicted-class labels shuffled across examples — preserves the 67/33 marginal (1348:652) but destroys the genuine correctness-asymmetry. Run as a **non-gating diagnostic** alongside the real candidate. Expected below `τ_lo`; the pre-committed caveat (§6) handles the case where it is not.
6. **Target-fit.** **Correctness is the right target** — a reliability question ("does the predicted class tell you when the detector errs, beyond confidence"). Class-B mechanistic, not a Class-C organizational/regime descriptor; no target mismatch.

## 3. Baseline, candidate, and §2 baseline-rule conformance

- **Baseline `B`:** detector **confidence** = `max(p,1−p)` — the folded (direction-discarding) magnitude.
- **Candidate observable `C`:** **`pred`** ∈ {0,1} — the binary predicted class (direction).
- **Ancestry Statement (spec §2.5; mechanistic per the Descriptor Justification Layer):** **`pred` (the predicted-class direction) extends `confidence` (the folded magnitude `max(p,1−p)`): it restores the direction the fold discards, and — under the pinned linear estimator — supplies a clean class-specific *intercept* shift (`w_B·B + w_pred·pred`), the exact lever a pure-intercept reliability asymmetry requires.** Mechanism: the detector's base correctness rate differs by predicted class (measured 14.1-pt gap); a magnitude-only baseline is structurally blind to it. The claim under test is that this asymmetry is information `confidence` does not already encode. *(`pred` is preferred over the continuous signed margin `p−0.5` precisely because the latter re-couples slope and intercept — the trap `[B,p]` already hit; `pred` gives the linear model the intercept-only lever the claimed mechanism needs.)*
- **§2 criteria (all five hold):** (1) **same substrate** — both from the same pinned model output; (2) **strictly simpler** — the HDG compares **nested** models `[B] ⊂ [B, pred]`, so the baseline (1 feature) is by construction never more complex than the candidate model (2 features), and the candidate strictly extends the baseline's feature set; (3) **pre-registered**; (4) **no post-hoc**; (5) **Ancestry Statement** above. Conforms.

## 4. HDG instantiation (pinned; inherited from the calibration) + the foil construction

- **Measure (spec §1):** `D` = HDG = `AUC_test(pipeline[B, C]) − AUC_test(pipeline[B])`, out-of-sample, AUC higher-is-better.
- **Estimator (identical to the calibration / #1–#3):** `Pipeline(StandardScaler(with_mean=True, with_std=True), LogisticRegression(solver='lbfgs', C=1.0, max_iter=1000, fit_intercept=True))`, fit on the training partition only (no leakage). `pred` z-scored by the same scaler.
- **Split protocol:** repeated **stratified 50/50 train/test splits** on `y`, **R = 200**, baseline and candidate **paired** (same train/test rows per replication). **Master seed `0xC1A55D`** — fresh, distinct from the calibration (`0xD37EC7`) and #1–#3 (`0x77C0DE`/`0x73C0DE`/`0xDEC0DE`). `SeedSequence(master).spawn(R)`, one child per replication.
- **The scalar `D` (pinned, identical form to #1–#3):** `D = median(HDG_AUC[1..200])` — ordinary median, all 200, **no trimming/winsorizing/sub-selection**; the verdict reads `D` alone.
- **Sensitivity panel (non-gating):** error-class **AP** median.
- **PERMUTED-PRED FOIL (non-gating diagnostic; pinned construction):** for each replication, on the **same split** as the real candidate (so real and foil share the identical baseline and partition), additionally compute `HDG_foil = AUC_test(pipeline[B, pred_perm]) − AUC_test(pipeline[B])`, where `pred_perm` is `pred` permuted across **all** examples. **Permutation RNG (independent of the real run, deterministic):** `foil_children = SeedSequence(MASTER_SEED ^ 0xF011).spawn(R)`; replication `r` permutes with `default_rng(foil_children[r])`. This yields 200 permuted-HDG values comparable to the 200 real values (same splits, same baseline; only `pred` → `pred_perm` differs). The **full permuted-HDG distribution and `D_foil = median`** are persisted as non-gating support. **The foil never enters `pred`'s verdict.**

## 6. Verdict rule (spec §6; pinned) + foil pre-commitment

The verdict for **`pred`** is read from the scalar `D` against the inherited band:

- **Validated** — `D > τ_hi`.
- **Not-Validated** — `D < τ_lo`: mechanism-agnostic in v0.1.
- **Inconclusive** — `τ_lo ≤ D ≤ τ_hi`: closed band; abstention, recorded with parity.

All three pre-committed and published identically; the verdict type is not predicted. Guards: inherited per-example-hash (§2), estimator-identity (§4), runtime cut-point assert (§5). Any guard failure invalidates the run (amended under a new tag), never silently proceeds.

**Foil pre-commitment (non-gating, pinned).** Expected: **`D_foil` (median permuted-pred HDG) below `τ_lo`** — and more strongly at or below 0 — because `pred_perm` is **target-independent** (the permutation destroys `pred↔correctness`, preserving only the 67/33 marginal frequency), and a target-independent feature cannot improve held-out AUC in expectation. The foil therefore doubles as a **band-validity / methodology check**: the band must reject it. **PRE-COMMITTED CAVEAT:** *if `D_foil` clears `τ_lo` (i.e. `D_foil ≥ τ_lo`, the persisted `foil_clears_tau_lo` condition — and especially if `D_foil > τ_hi`), that is a **methodological red flag**, not evidence of legitimate marginal structure — a target-independent feature should not lift out-of-sample AUC, so a cleared foil points to an artifact (permutation/independence bug, leakage, estimator or band pathology) to investigate **before** `pred`'s verdict is interpreted. `pred`'s gating verdict is unaffected (the foil is non-gating), but a cleared foil **suspends interpretive trust** in the run pending that investigation.* The foil result is reported regardless; it never enters `verdict_of`.
