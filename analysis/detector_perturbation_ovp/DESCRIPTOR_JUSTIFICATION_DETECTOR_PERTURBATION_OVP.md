## §0.5 Descriptor Justification (locked disclosure — NOT an admission gate)

### 1. Mechanism (disclosed)
The detector's `confidence` is a function of a **single forward pass**. It is structurally blind to the detector's **instability under input perturbation**: texts whose `predicted_prob_ai` *swings* when the text is paraphrased (meaning preserved, surface form changed) are ones on which the detector is unreliable, and that swing is information **no single output of the detector contains**. Self-consistency / ensemble-disagreement as error predictors are documented (self-consistency for LLM reasoning; ensemble-disagreement as a calibration probe is older). Mechanism-first, not availability: the candidate is generated by "what information is the detector's single-pass confidence *constitutionally* unable to see," not by "what column do we already have."

### 2. Baseline-blindness argument (the mechanistic Ancestry — the cleanest the program has written)
`B = max(p, 1−p)` is computed from **one** detector forward pass on the original text. `perturbation_spread` requires a **second (and further) forward pass** — the detector re-run on paraphrases — to compute. So **C contains information B's single-pass nature *structurally cannot contain*.** This is the §2.5 Ancestry upgraded from *structural* ("B is a simpler function of C") to *mechanistic and provable*: every prior detector candidate (`truncated`, `text_length` — input features; `predicted_prob_ai`, `pred` — the same single-pass probability) drew from the **same information source as B** and was, as predicted, absorbed (Inconclusive / Not-Validated). C is the first from an **independent information source**.

*Conformance note (§2):* same substrate (the same pinned detector model, the same 2000 RAID examples, the same `y`); C strictly extends B — **C carries variance information across paraphrases that B (a single-point magnitude of the original) cannot carry, even though C's input space includes the original `p` that B is derived from. The information distinction is statistical (spread vs point), not algebraic: a logistic on `[B]` alone cannot fit C's contribution because C is not a function of B.** **One honest departure from #1–#4:** C requires **new materialization** (a paraphraser + paraphrases + detector re-runs), so this candidate is a *hybrid* — inherit `B`, `y`, and the band from the locked substrate; **materialize C fresh** under its own pinned dependencies (paraphraser model+revision+decoding+seed; K; the spread statistic), hashed once and inherited by the judge exactly as the original per-example was.

### 3. Dual interpretation — pre-committed and locked (sharpened by the real prior-of-positive)
Because this candidate has a **genuine prior to Validate**, both readings must be honest *before the run* to foreclose post-hoc spin in either direction:

- **If Validated:** perturbation-disagreement adds discriminative information **beyond single-pass confidence, on this substrate, under this estimator, against the inherited band.** It does **NOT** establish that this generalizes beyond the detector, nor that the magnitude is practically useful — **only** that the structural orthogonality argument was correct on this run.
- **If Not-Validated:** confidence **already absorbs** the perturbation-disagreement signal — i.e., the detector's *training* has effectively encoded the same instability information into its single-pass output, even though the single pass cannot *compute* it at inference. **Do NOT reach for "the paraphraser was too weak"** — that escape is foreclosed *unless* paraphraser quality is verified against the **pre-committed paraphraser-quality control** (below) *before* interpretation.
- **If Inconclusive:** C sits in the band; no legitimacy claim.

**Anti-rescue control (pinned, pre-run):** paraphrase validity is a **methodological control checked before any verdict is interpreted**, never a post-hoc excuse. Pre-commit: paraphrases must clear a fixed semantic-fidelity bar (e.g., embedding cosine ≥ θ to the original, and surface-form change ≥ δ — both pinned), measured on the full set; a Not-Validated is interpreted as §3 states **only if** the paraphrase set passed this control. If the control *fails*, the run is a materialization defect (amend under a new tag), not a verdict.

### 4. Surface foil (the hard one — flagged for the warm pass)
**Primary foil (band-validity / target-independence, same construction as #4's permuted-`pred`):** **permuted `perturbation_spread`** — the spread scores shuffled across examples (independent deterministic stream). This preserves C's exact marginal while destroying `C↔y`, so it is **target-independent** and, per §6, must land **below `τ_lo`** (a material `D_foil ≥ τ_lo` is a **methodological RED FLAG**, not legitimate signal). The permutation is sufficient *for the target-independence/band-validity purpose* because permuting the *final* spread scores gives a feature with C's marginal and no link to `y`, regardless of how C was computed.

**The non-trivial part you flagged — a confound, distinct from target-independence.** The worry isn't "is it the per-example link vs the marginal" (the permutation foil handles that); it's **"is the gain genuine instability, or a proxy for a text property the paraphrasing co-varies with"** — most obviously **length** (longer texts may paraphrase more variably → C correlates with `text_length` → C could Validate *via* length, not instability). The clean control is a **non-gating confound diagnostic**: HDG of C beyond `[B, text_length]` (and domain) — does C add over confidence *and* length? If the gain survives, it is not a length/domain proxy. (Your "disagreement on paraphrases of *unrelated* texts" idea is the permutation generalized to an external corpus — equivalent for target-independence, but the within-set permutation is cleaner and reuses the materialized scores; the *confound* question is better served by the covariate diagnostic than by either permutation.)

**DISCHARGED (warm pass):** primary permuted-C (target-independence / band-validity) **plus** the length/domain covariate diagnostic (confound) together cover the foil's job; the multi-pass construction needs no further control. Two points pinned:
- **The "C is a transformation of B" worry is auto-handled by HDG itself** — if C were a deterministic function of B (e.g. spread rising near `p=0.5`), the augmented logistic `[B,C]` gains nothing out-of-sample and `HDG ≈ 0`. So the diagnostic only needs to address confounds that are **in C but not in B** — i.e. `text_length` and `domain`.
- **Confound-diagnostic criterion (non-gating, pinned, with the #4-style caveat):** compute `HDG_extended` = HDG of C beyond `[B, text_length, domain]` (domain one-hot under the single-feature constraint, or a sensitivity panel if encoding is awkward), reported alongside `HDG_primary` = HDG of C beyond `[B]`. **The gain is interpreted as genuine perturbation-instability iff `HDG_primary − HDG_extended ≤ ε_confound`** (adding the covariates does *not* materially absorb C). If `HDG_extended` collapses toward 0 while `HDG_primary > 0`, the gain is length/domain-mediated and the result document carries that caveat — same epistemic level and caveat structure as #4's `foil_clears_tau_lo`. *(Note: your warm-pass lead sentence phrased this as "HDG_extended is at least ε_confound below HDG_primary," which inverts relative to your two worked examples; I've encoded the examples' intent — gain survives the covariates ⇒ genuine; gain collapses ⇒ proxy caveat. Confirm.)*

### 5. Target-fit (the Class-C guard)
**Correctness is the right target.** This is squarely a reliability question — "does instability-under-paraphrase predict when the detector errs, beyond confidence." Class-B mechanistic, not a Class-C organizational/regime descriptor; no target mismatch.

### 6. The genuine uncertainty (what is actually being tested — sealed)
The verdict does **not** follow from the mechanism being real (it is — the single pass provably can't see the spread). It hinges on whether **confidence already absorbs the spread signal** via training (§3, Not-Validated reading). That is unknown and sealed until the locked run; the structural-orthogonality argument raises the prior of positive **above zero** but does not predetermine it. This is the program's first candidate where that prior is genuinely non-trivial.
