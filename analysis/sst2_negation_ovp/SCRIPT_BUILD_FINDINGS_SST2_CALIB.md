## Smoke validation (non-canonical seed, numpy-only logistic, SIMULATED (B, y))

The sandbox cannot run DistilBERT or sklearn, so the calibration **logic** was exercised on a simulated SST-2-like substrate (confidence skewed high ~0.92; correctness ~91%, genuinely increasing in confidence; 872 examples, ~76 errors), numpy IRLS logistic, R=200 stratified splits.

Result:
- baseline `AUC(B→correctness)` median ≈ 0.627 (confidence predicts correctness, as expected).
- null P95: redundant 0.0000 (affine of B, exactly collinear), noise **0.0133** (wide upper tail from the small error class — the imbalance effect, exactly as the warm reviewer flagged) → `τ_lo = 0.0133` via max-of-95ths.
- meaningful sweep mean HDG monotone decreasing in σ_m {0.5:0.295 … 4.0:−0.026}; clearing points (P5 > τ_lo+δ) = {0.5, 1.0}; `τ_hi = P5(σ_m=1.0) = 0.0505`.
- **USABLE BAND** `[0.0133, 0.0505]` — separability held on simulated imbalanced data.

Reads:
1. **No design blocker.** The calibration logic behaves correctly (nulls ≈ 0 with imbalance-widened tails, meaningful gradient monotone, max-of-95ths correctly governed by the noise null). Unlike the positive control's Arm 3, the smoke surfaced nothing to fix.
2. **Imbalance risk real but not fatal (in simulation).** τ_lo is pushed ~15× higher than the synthetic positive control's; the band is narrow and high. A band survived here, but this is **simulated** data — the real locked run on the actual DistilBERT outputs is the only definitive separability answer, and MIS-SPECIFIED remains a genuine pre-committed possibility (pre-reg §6).
3. **Downstream implication (lock 2):** the high floor means negation must add >0.0133 AUC to escape Not-Validated and >0.0505 to be Validated — a stiff bar, so Not-Validated/Inconclusive on negation is a likely and honest first ledger entry.

## σ_m grid refinement (2026-06-07) + re-smoke

**Change.** The meaningful sweep grid was refined from **{0.5, 1.0, 1.5, 2.0, 3.0, 4.0}** to **{0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0}** — uniform 0.5 spacing across the full range. Rationale: the prior grid had 0.5 spacing at the low-σ_m end but 1.0 spacing past σ_m=2.0, which is exactly the high-σ_m region where the `τ_hi` "weakest-clearing-point" rule operates by construction; the added 2.5/3.5 are the most likely weakest-clearing candidates, so the refinement puts fine resolution where `τ_hi` is determined. This converts the previously-queued grid-resolution non-blocker into a fix applied *before* lock (cheap now: +2 grid points × R_cal=200 ≈ a second of extra compute; no pass count to reset since no cold pass had touched the refined bytes). Operator decision (Option 2). Pre-reg §4/§5/§6/§11.4 and the script's `SIGMA_M_GRID` updated to match.

**Re-smoke (refined 8-pt grid, numpy-only logistic, SIMULATED (B,y)).** baseline AUC median ≈ 0.629; nulls non-positive (P95 redundant 0.0000, noise 0.0173 → τ_lo=0.0173); meaningful sweep **strictly monotone over all 8 points** (0.295/0.150/0.077/0.045/0.023/0.016/0.012/0.005); weakest-clearing σ_m=1.0 → τ_hi=0.0809; **USABLE BAND [0.0173, 0.0809]** (gap 0.064 ≥ δ). The 8-point monotonicity check passed — a longer monotone sequence than the prior 6-point grid required, the free sanity-check benefit. In this particular simulation the 2.5/3.5 points did not bind the weakest-clearing pick (1.5 already failed to clear), which is an artifact of the simulation's noise, not the design; they provide resolution if the **real** substrate's weakest-clearing point lands in the high-σ region. **No design blocker.** (Smoke band differs from the prior 6-pt smoke's [0.0133, 0.0505] only because the simulated substrate is re-drawn each smoke; the real locked run is the only definitive band, and MIS-SPECIFIED remains a genuine pre-committed possibility.)

## AP error-class fix (2026-06-07) — bundled with the grid refinement

**Change (operator Option A).** A cold-pass-2 non-blocker logged as "informal labeling" was, on code review, a real intent-vs-implementation mismatch: §3 named AP as the *imbalance-robustness* panel "focused on the rare error class," but the code computed `average_precision_score(yte, p2)` — AP on `y=1` = **correct** = the ~91% **majority** class. AP is class-asymmetric (AUC is not), so the computed quantity did not serve the panel's stated purpose. Fixed in `hdg()`: AP now treats **error as positive** — `average_precision_score(1 − yte, 1 − p2) − average_precision_score(1 − yte, 1 − p1)` (relabel `1−y`, score predicted error probability `1−P(correct)`), for both candidate and baseline. The fitted logistic models are unchanged; only the AP read-out changes. §3 gains a pinned implementation sentence; §6/§11.1 updated. (Also folded in the same §3 edit: the cold-pass-2 "new version → new pre-registration" wording fix, aligning §3/§6 with spec §1/§6.) AP remains **non-gating** — `τ_lo`/`τ_hi` are AUC-only.

**Re-smoke (corrected AP, 8-pt grid, simulated (B,y)).** Band **unchanged** (`τ_lo=0.0173`, `τ_hi=0.0809`) — confirms AP does not touch the cut points. AP panel now behaves correctly: nulls non-positive (redundant +0.0000, noise −0.0246), meaningful arms strongly positive and monotone decreasing (+0.478/+0.160/+0.059/+0.026/+0.005/−0.001/−0.003/−0.010), and the strongest meaningful ΔAP (+0.478) **exceeds** its ΔAUC (+0.295) — the rare-class amplification the panel is meant to provide. **No design blocker.** (The smoke's auto-assert used a two-sided null threshold and printed a spurious False; the correct one-sided criterion "null ΔAP not meaningfully positive" holds.)

**Downstream (lock 2):** the candidate study inherits the corrected error-class AP. A `negation_count` verdict that is Not-Validated on AUC but shows positive error-class ΔAP becomes interpretable as "negation may add error-detection information without improving overall discrimination" — a real signal for a future AP-primary pre-registration. The mis-implemented AP would have surfaced nothing.
